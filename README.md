# 📊 Walmart Sales Forecasting – Updated Project

This repository contains the updated and improved version of my Walmart Sales Forecasting Capstone Project.
The project analyzes weekly sales data across multiple Walmart stores and builds time-series forecasting models to support better inventory and business planning.

Project Overview
1. Performed EDA to understand trends, seasonality, and patterns.
2. Analyzed influence of Unemployment, CPI, Temperature.
3. Identified top & worst performing stores.
4. Built SARIMA forecasting models for 5 stores.
5. Generated 12-week sales predictions.

Objectives
1. Analyze factors affecting weekly sales.
2. Study seasonal patterns and holiday effects.
3. Build accurate time-series forecasting models.
4. Provide actionable insights for decision-making.

Techniques Used
1. AR, ARIMA, SARIMA models
2. Seasonal decomposition
3. ACF/PACF analysis
4. Train-test forecasting evaluation

Key Insights
1. Strong seasonality around major holidays
2. Unemployment & CPI influence sales
3. Temperature has minimal impact
4. SARIMA outperforms AR and ARIMA
5. Forecasts help optimize inventory planning
